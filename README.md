# 📄 LLM Document Insight Extractor
**LLM Document Insight Extractor** is a Streamlit-based application that leverages a locally hosted large language model (LLM) to extract insights from uploaded documents (PDFs and text files). Designed for quick analysis, it enables users to summarize documents, identify key insights, and perform advanced text analysis.

### ✨ Features
- **Multiple Document Support:** Upload and analyze PDFs or text files.
- **AI-Driven Summarization:** Generate insights using a locally hosted LLM (Llama-3.2-3B).
- **Custom Prompts:** Ask targeted questions to get specific responses from the LLM.
- **Interactive UI:** Built with Streamlit for a clean and responsive interface.
- **Text Extraction and Analysis:** Preview extracted document content before running queries.

### 🚀 How to Use
1. Clone the repository and install the dependencies.
2. Run the app with `streamlit run app.py`.
3. Upload a document and input a prompt.
4. Generate responses to get AI-driven insights.

### 🛠️ Tech Stack
- **Python** – Core programming language
- **PyTorch** – For loading and running the language model
- **Transformers** – Hugging Face's library for managing the LLM
- **Streamlit** – For building the interactive web app

### 📚 Use Cases
- Summarizing lengthy documents
- Extracting key insights from business reports
- Analyzing research papers and generating concise summaries
- Financial data insights and compliance checks
